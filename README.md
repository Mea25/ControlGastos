# ControlGastos

## Descripción
ControlGastos es una aplicación Android desarrollada en Kotlin para registrar y consultar ingresos y gastos personales.

## Funcionalidades
- Registrar ingresos y gastos.
- Ingresar una descripción, monto y categoría.
- Consultar el total de ingresos.
- Consultar el total de gastos.
- Calcular el saldo disponible.
- Mostrar un historial de movimientos.
- Almacenar movimientos localmente mediante SQLite.

## Tecnologías utilizadas
- Kotlin
- Android Studio
- SQLite
- Gradle
